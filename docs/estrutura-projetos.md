# Estrutura dos projetos do Ômega

O repositório mantém os projetos prontos para estudo em pastas de primeiro nível. Os projetos ativos têm uma estrutura comum, enquanto os diretórios originais foram preservados para consulta e comparação.

## Projetos ativos

| Pasta | Responsável ou origem | Situação |
| --- | --- | --- |
| [`cloneYou`](../cloneYou) | Consolidação dos três projetos de clone do YouTube | Versão principal, com documentação e dois módulos opcionais. |
| [`wiki-modern-warfare`](../wiki-modern-warfare) | Pedro | Wiki recriada com história do MW1 ao MW4. |
| [`portfolio-talles`](../portfolio-talles) | Talles | Portfólio recriado com identidade visual e menu mobile. |
| [`estacao-pc`](../estacao-pc) | Felipe | Site de PCs recriado com componentes e perfis de montagem. |

Cada projeto ativo segue o mesmo padrão:

```text
projeto/
├── index.html
├── css/style.css
├── js/script.js
├── assets/       # quando existem imagens locais
└── README.md
```

## Diretórios originais preservados

Os diretórios abaixo continuam no repositório para que os alunos possam comparar a ideia inicial com a versão organizada. Eles não foram misturados aos projetos ativos para evitar que arquivos antigos ou nomes de CSS com erros quebrem as versões finais.

| Pasta original | Observação |
| --- | --- |
| `site_DuDuzinVideoJogus_01` | Base original de projeto de vídeos. |
| `site_pedrocamposcoimbra8-afk_01` | Base inicial do projeto do Pedro. |
| `site_felipebrayan1403-cell_01` | Scaffold inicial do site de PCs do Felipe. |
| `site_ajuda_pensamento_01` | Projeto educacional original preservado no repositório. |
| `ALFA` | Pasta original adicional preservada para consulta. |

> Para novas alterações, os alunos devem trabalhar nas quatro pastas ativas. Os diretórios originais funcionam como histórico de aprendizagem e não devem ser editados sem necessidade.
