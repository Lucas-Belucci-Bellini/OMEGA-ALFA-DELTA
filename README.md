# OMEGA-ALFA-DELTA

## Projeto CloneYou

A pasta [`cloneYou`](./cloneYou) contém um clone educacional de uma plataforma de vídeos, consolidado a partir das referências dos repositórios dos colegas. O projeto inclui cabeçalho, logo com efeito de crescimento ao passar o mouse, busca, filtros, menu lateral, cards de vídeos, modal de prévia e layout responsivo.

Para executar, abra [`cloneYou/index.html`](./cloneYou/index.html) no navegador. Consulte o [guia do aluno](./cloneYou/README.md) para entender a estrutura e as atividades sugeridas.
