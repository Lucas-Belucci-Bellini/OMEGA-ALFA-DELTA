# OMEGA-ALFA-DELTA

Este repositório reúne projetos educacionais desenvolvidos pelos alunos. Cada pasta é independente e pode ser aberta pelo seu próprio `index.html`, permitindo estudar HTML, CSS e JavaScript por etapas.

## Projetos

| Pasta | Tema | O que estudar |
| --- | --- | --- |
| [`cloneYou`](./cloneYou) | Clone educacional do YouTube | Grid de vídeos, busca, filtros, sidebar expansível, modo escuro e modal. |
| [`wiki-modern-warfare`](./wiki-modern-warfare) | Wiki Modern Warfare | Linha do tempo do MW1 ao MW4, filtros de capítulos e link meme para o YouTube. |
| [`portfolio-talles`](./portfolio-talles) | Portfólio do Talles | Apresentação pessoal, cards de favoritos, tipografia e menu mobile. |
| [`estacao-pc`](./estacao-pc) | Estação PC | Componentes de computador, perfis de montagem, abas e dicas. |

## Como executar

Abra a pasta escolhida e depois abra o arquivo `index.html` no navegador. Os projetos são front-end estáticos, portanto não precisam de banco de dados ou instalação de dependências para funcionar.

Para aprender com o código, comece pelo HTML, identifique as classes usadas no CSS e depois observe os eventos no JavaScript. Cada projeto possui um README próprio com atividades sugeridas.

## Documentação do CloneYou

A pasta [`cloneYou`](./cloneYou) contém um clone educacional de uma plataforma de vídeos, consolidado a partir das referências dos colegas. O projeto inclui cabeçalho, logo com efeito de crescimento ao passar o mouse, busca, filtros, sidebar recolhível, modo escuro, cards de vídeos, modal de prévia e layout responsivo.

A integração das três fontes originais está registrada em [`cloneYou/docs/integracao-fontes.md`](./cloneYou/docs/integracao-fontes.md). Os comentários sobre o layout CSS, o estado JavaScript e os testes ficam na documentação da pasta.

## Estrutura recomendada para os alunos

```text
projeto/
├── index.html          # estrutura e conteúdo
├── css/
│   └── style.css       # aparência, layout e responsividade
├── js/
│   └── script.js       # eventos e comportamento
├── assets/             # imagens usadas no projeto
└── README.md           # guia de estudo
```
