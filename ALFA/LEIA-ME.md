# ALFA — material original preservado

> **Está quebrado de propósito. Não conserte.**

Pasta original preservada como histórico de aprendizagem. Ela não tem uma versão
organizada correspondente entre os projetos ativos.

## O que acontece ao abrir `index.html`

| Sintoma | Causa |
| --- | --- |
| A página abre sem nenhum estilo | O `<link>` pede `style.css`; o arquivo se chama **`stlye.css`** |
| Nenhuma das 9 imagens aparece | Os arquivos `.jfif`/`.jpg` referenciados nunca foram enviados ao repositório |

Duas letras trocadas em um nome de arquivo bastam para a página perder todo o
visual — e o navegador não avisa em lugar nenhum da tela. O erro só aparece na
aba **Rede** das ferramentas de desenvolvedor, como um `style.css` em vermelho.

## Por que fica assim

Este repositório guarda o começo de cada projeto para que dê para comparar. Um
defeito preservado ensina; um defeito corrigido some da história.

A decisão completa está em [`../docs/MATERIAL-PRESERVADO.md`](../docs/MATERIAL-PRESERVADO.md).
